# E-commerce Customer Analytics

## О проекте

Проект посвящен анализу клиентской базы интернет-магазина с целью выявления факторов, влияющих на выручку, удержание пользователей и эффективность бизнеса.

В рамках проекта был выполнен полный цикл аналитической работы: от подготовки и очистки данных до проверки статистических гипотез и формирования рекомендаций для бизнеса.

---

## Цель исследования

Понять особенности поведения клиентов интернет-магазина и определить направления для повышения эффективности бизнеса.

---

## Используемые данные

Проект основан на данных интернет-магазина и включает информацию о:

* заказах пользователей;
* стоимости покупок;
* времени совершения заказов;
* странах покупателей;
* клиентских идентификаторах.

## Этапы работы

### 1. Предобработка данных

* проверка качества данных;
* обработка пропусков;
* корректировка типов данных;
* поиск и удаление аномалий.

### 2. Исследовательский анализ данных (EDA)

* анализ структуры клиентской базы;
* анализ динамики заказов;
* исследование сезонности;
* анализ распределения выручки;
* анализ среднего чека.

### 3. Анализ поведения клиентов

* расчет доли возвратных клиентов;
* анализ активности пользователей;
* расчет Sticky Factor;
* исследование различий между сегментами покупателей.

### 4. Сегментация клиентов

Проведена RFM-сегментация пользователей для выделения наиболее ценных групп клиентов.

### 5. Проверка статистических гипотез

Проведено сравнение показателей различных групп клиентов с использованием статистических методов.

### 6. Формирование рекомендаций

На основе результатов анализа сформулированы рекомендации по развитию бизнеса и повышению удержания клиентов.

---

## Ключевые результаты

* Выполнен полный цикл анализа клиентских данных интернет-магазина.
* Выявлены особенности поведения возвратных и новых клиентов.
* Проведена сегментация клиентской базы методом RFM.
* Определены наиболее ценные сегменты пользователей.
* Проверены бизнес-гипотезы статистическими методами.
* Подготовлены рекомендации для повышения эффективности бизнеса.
